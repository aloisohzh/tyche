# Local LEAN lane smoke + PB-001 hypothesis — 2026-11-19

**Verdict: lane smoke PASS · hypothesis NO-GO as an alpha claim (sanity-checked, not validated).**

First run of the ADR-0015 local LEAN validation lane. The lane works end to end
(hypothesis → local data → engine backtest → evidence with provenance). The
PB-001 reference hypothesis earns a positive net return but **does not beat
cash on a risk-adjusted basis** over the test window, so it stays unvalidated
and must not be pre-registered as edge. Consistent with PB-001's own stance:
beta and ballast, not alpha.

## Data provenance

- Source: **yfinance** daily OHLCV, `auto_adjust=True` (total-return adjusted
  bars), 11 universe ETFs, 13,475 rows, 2022-01-03..2026-11-18, fetched
  2026-11-19 via `scripts/fetch_research_prices.py` → `data/research/ohlcv.csv`
  (gitignored).
- Conversion: `scripts/make_lean_data.py` → per-symbol daily zips under
  `research/lean/data/equity/usa/daily/` in LEAN's **deci-cent integer** format
  (price × 10000). Adjustments are baked into the bars; map/factor files are
  empty and the algorithm uses `DataNormalizationMode.RAW`. This is a
  disclosed approximation, not split/dividend-exact history.
- Engine support files (symbol properties, market hours, USA interest-rate
  csv) pulled from Lean master. The interest-rate file matters: it sets the
  risk-free rate used in Sharpe/Sortino.
- Data is research-only; nothing here feeds the kernel (ADR-0015 §3).

## Fill and cost model (verified, not assumed)

- `set_holdings` at daily resolution fills **market-on-open at the next bar's
  open**. Verified against order events: first fill IWM buy 549 @ 167.0316 on
  2023-01-04 21:00 UTC equals the CSV IWM open for 2023-01-04 (signal bar
  2023-01-03 open 168.2846 / close 165.8646). No same-bar lookahead.
- Fees: Interactive Brokers brokerage model (per-share), total **$2,387.76**
  over 287 orders. Slippage: engine default volume-share model. Neither is
  moomoo sim's cost structure — results are claims about this venue only.

## Deviations from the kernel PB-001 reference

1. Weekly rebalance gate (ISO week change) vs the kernel's daily drift-band check.
2. Sleeve caps scale positions down **without redistribution** to other sleeves.
3. No tyche risk kernel: no gross/min-cash/halt/drawdown gates; only the
   algorithm's own 95% invested cap, 20% relative drift band and min-trade floor.
4. Momentum/vol math mirrors the playbook (horizons 63/126/252 at 0.5/0.3/0.2,
   skip 5, inverse-vol weights, 126d covariance vol-target 10%), but this is a
   separate research code path, not the trading kernel.

## Interpretation (honest)

- **NO-GO as alpha.** With the USA risk-free rate file loaded (recent years
  ~4–5%), a 5.52% CAGR leaves essentially zero excess over cash; the engine's
  Sharpe is negative (−0.254). Trade-level profit factor 2.11 and 65% win rate
  do not rescue a portfolio that merely tracks its beta sleeve.
- **Risk path observation only.** 8.1% max drawdown and 5.8% realized vol
  (below the 10% target — sleeve/instrument caps and cash drag bind) are
  consistent with PB-001's ballast role. That is a risk-profile observation,
  not evidence of edge.
- Per the validation convention this setup is **sanity-checked at best**;
  the label "validated" remains reserved for the parked full gauntlet
  (bootstrap LB, matched null, folds). No pre-registration from this run.

## Incident disclosure (append-only honesty)

Three earlier runs were artifacts and their output dirs were deleted:

- `03-12-13`, `03-36-13`: Python API errors (`dataNormalizationMode` kwarg,
  `invested_value` attribute) — fixed to snake_case / `holdings_value`.
- `03-37-33`: converter wrote **decimal** prices where LEAN expects deci-cent
  integers → ~10,000× share counts (IWM 5,492,621 @ 0.01670316), fees
  $355,555.33 = exactly 1% of volume, net −14.018%. Diagnosed from order
  events vs the source CSV; converter fixed (`int(round(price * 10000))`),
  data regenerated, run `03-40-54` is the valid one. Lesson recorded: always
  reconcile first fills against the source bars before trusting statistics.

## How to read it

- Account value per day is the broker's total asset from `eod.reconcile`; a day with no reconcile uses the last published desk mark for that date, and a day with neither is left out, never carried. Journal rows for another account are dropped by their masked id; a row whose id is redacted (sanitized bundles) is kept.
- The SPY baseline is the same starting cash put into SPY at the base day's close with no fees, which flatters SPY slightly; it is the bar, not a strategy.
- Returns are fee-net because the account value already carries the modelled fees reconciled to cash.
- Vol and Sharpe annualize with sqrt(252) over n daily marks; drawdown is from the running peak of the marks shown.
